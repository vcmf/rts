# Prototypes

Single-file prototypes (Babylon.js 9 for 3D, Canvas 2D for maps). `painted-cinematic.html` is the
current world prototype, `staff-map.html` the staff-map feel prototype and `formation-map.html` the
formation test (2D map; its logic is in `formation-core.js`, shared as a plain script); the others
are earlier steps kept for comparison.

- **Single file, runnable from `file://`**: no build step, Babylon from the CDN at a pinned
  version. Generated model data goes in `*.data.js` (committed, regenerated by `tools/`).
- **GLSL in template strings**: no apostrophes or words like `ground's` in comments inside shader
  source (Babylon's preprocessor chokes on some comment text); keep shader comments minimal.
- **Comments**: one short comment on non-obvious code, the why, not the how. Reference docs by
  repo path (`docs/art-bible.md` §6c), so `tools/check-docs.mjs` can verify them.
- **Verify with the tools**: `tools/shot.mjs` for screenshots, `tools/river-check.js` and
  `tools/render-check.js` for the river and render invariants. Every new check gets a negative test
  (break the thing, see the check fail).
- **Pack colours are never used**: materials map to roles and our palette paints them
  (`docs/art-bible.md` §4b).
- **Load time**: compare against main with paired runs of the same marker (`window.__buildMs`).
